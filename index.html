Variables

Concept: Variables store data. Use let (reassignable) and const (constant). Avoid var (old, function-scoped).

Types: string, number, boolean, null, undefined, object, symbol, bigint.

Naming: camelCase, no starting with digits, no reserved words.

Template literals: `Hello ${name}`.

1. Declare a variable age equal to 42.

2. What is the output of: typeof "hello"?

3. What is the output? let x; console.log(x);

4. What is the output? const y = null; console.log(typeof y);

5. Write a template literal that outputs Hi Sam using name="Sam". Type the whole expression.

6. Which keyword makes a constant? (let/const/var)

7. What is typeof true?

8. Convert the string "5" to number and add 3. What is the result?

9. What is the output? let a = 5; a = 10; console.log(a);

10. What will const b = 1; b = 2; do?

Operators

Concept: Operators combine values.
Arithmetic: + - * / % ** · Comparison: == === != !== < > <= >= · Logical: && || ! · Assignment: = += -= *= /= · Ternary: cond ? a : b

⚠️ == does type coercion; === does not. Prefer ===.

1. What is 5 + 3?

2. What is "5" + 3?

3. What is 10 % 3?

4. What is 2 ** 4?

5. What is 5 == "5"? (true/false)

6. What is 5 === "5"?

7. What is !true?

8. What is true && false?

9. What is true || false?

10. Evaluate let x=5; x+=3; console.log(x) — what is x?

11. Use ternary to express: if age≥18 → "adult", else "minor". Type the expression.

12. What is 10 / 0?

13. What is null ?? "default"?

14. What is 0 || "fallback"?

Control Flow

Concept: Control flow decides which code runs.
if / else if / else · switch · for, while, do…while, for…of, for…in · break, continue, return.

1. What prints? if (5 > 3) console.log("yes"); else console.log("no");

2. What prints? for(let i=0;i<3;i++) console.log(i) — list output space separated.

3. What is the output? [1,2,3].forEach(n=>console.log(n*2))

4. What is [1,2,3,4].filter(n=>n%2===0).length?

5. What is [1,2,3].map(n=>n+10)? (comma separated)

6. How many times does a while(i<5) loop run if i starts at 0?

7. What does break do inside a loop?

8. What does continue do?

9. What prints? for(let i=0;i<5;i++){ if(i===3) break; console.log(i) }

10. What prints? for(let i=0;i<5;i++){ if(i===2) continue; console.log(i) }

11. Write a switch statement matching case 'a' → "Alpha". Type just the keyword used to begin a case.

12. What prints? let s=""; for(let i=1;i<=3;i++) s+=i; console.log(s);

13. Which loop guarantees at least one execution? (for/while/do…while)

14. What is the output? [1,2,3].reduce((a,b)=>a+b, 0)

Mini Projects

Solve these on paper or in a separate editor. When done, click Mark Complete. Each project has a concept recap.

🎯 Project 1 — FizzBuzz

Print 1..100. Multiples of 3 → "Fizz", of 5 → "Buzz", of both → "FizzBuzz".
Concepts: loop + modulo + if/else.

🎯 Project 2 — Palindrome Checker

Function isPalindrome(str) that ignores case/spaces. Example: "Never odd or even" → true.
Concepts: string methods, loop, comparison.

🎯 Project 3 — Grade Calculator

Given score 0–100 → A (≥90), B (≥80), C (≥70), D (≥60), F otherwise. Use a switch(true) or if/else chain.
Concepts: control flow, ranges.

🎯 Project 4 — Word Frequency Counter

Count occurrences of each word in a sentence. Return an object like {hi:1, there:2}.
Concepts: objects, split, loop.

🎯 Project 5 — Temperature Converter

Toggle between Celsius and Fahrenheit with a button; show result with 2 decimals.
Concepts: functions, operators, DOM basics.

🎯 Project 6 — Simple Calculator

Four operations with switch. Validate division by zero.
Concepts: switch, operators, validation.

🎯 Project 7 — Number Guesser

Random number 1..100. Loop with feedback "higher/lower" until correct, count guesses.
Concepts: while, break, Math.random.

🎯 Project 8 — Star Pyramid

Print a pyramid of stars height N (nested loops).
Concepts: nested loops.
